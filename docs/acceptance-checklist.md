# ImageLab acceptance checklist

| Requirement | Steps performed | Expected result | Actual result | Pass/Fail | Evidence |
|---|---|---|---|---|---|
| Initial page | Reloaded page and watched Network for 5 seconds | No selected image, active job, results, or polling | No image, active job, results, upload requests, or status requests appeared | Pass | [Initial state](evidence/01-initial-state.png) |
| Local preview without upload | Selected a valid image without clicking Process image; watched Network for 5 seconds | Preview and file details appear without uploading or polling | Preview and file details appeared; no upload POST or status GET was sent | Pass | [Local preview](evidence/02-local-preview.png) |
| Accepted response | Submitted one image; inspected POST Headers and Response | HTTP 202 with image_id, job_id, queued status, status_url, and matching Location | Response contained all required fields; Location matched status_url and job_id | Pass | [Headers](evidence/03-upload-headers.png), [Response](evidence/04-upload-response.png) |
| Saved job and timestamps | Queried the accepted job by its public ID | Matching image ID, completed status, ordered queue/start/completion timestamps, and no failure timestamp | Matching job found; timestamps were ordered and failed_at was empty | Pass | [Job record](evidence/05-job-record.txt) |
| Saved variant metadata | Queried variants belonging to the accepted image | Three named variants with expected dimensions and positive sizes | Found thumbnail 150×150, preview 800×600, and display 1200×900; all sizes positive | Pass | [Variant records](evidence/06-variant-records.txt) |
| Active polling | Submitted an image and watched Network during processing | Repeated status requests; visible polling message; completion remains pending | Repeated requests appeared while Processing; automatic-checking message visible; Complete remained pending | Pass | [Active polling](evidence/08-active-polling.png) |
| Polling stops on completion | Inspected the completed response and watched Network for another 5 seconds | Completed UI and results; no further job-status requests | Completed response received, results displayed, and no additional status requests appeared during the observation period | Pass | [Polling stopped](evidence/09-polling-stopped.png) |
| Polling stops on failure | Watched Network for 5 seconds after receiving failed status | No further automatic status requests | No additional status requests appeared | Pass | [Failure UI](evidence/13-processing-failure.png) |
| Double-click protection | Rapidly double-clicked Process image after selecting a valid image | Only one upload POST | Network showed one images upload followed by status requests; job completed | Pass | [Double-click check](evidence/15-double-click-protection.png) |
| Selection cancels observation | Selected another valid image during processing and watched Network for 5 seconds | Clear old job/results; stop observing old job; do not upload the selection automatically | New preview appeared, job display cleared, and no further old-job requests or automatic upload occurred | Pass | [Selection reset](evidence/16-selection-cancels-observation.png) |
| Submission after selection reset | Clicked Process image after replacing the selection | Create and observe a new job; display its results | A second upload returned a different job ID and completed successfully | Pass | [New job completed](evidence/17-replacement-image-completed.png) |
